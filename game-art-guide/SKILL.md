# 游戏美术规范

目标：让 AI 生成的游戏画面达到「风格统一、配色讲究、有质感」的水准，而不是一堆 CSS 纯色块。全程只做一件事——**先定风格和配色，再动手写代码**。

## 核心原则（违反任何一条美术都会崩）

1. **不要用 CSS 纯色块硬画**——优先用游戏引擎、现成素材或程序化生成来表现画面。
2. **先定风格 + 配色，再动手**——风格是美术的骨架，中途换风格 = 推倒重来。
3. **一套游戏只用一种风格 + 一个有限调色板（≤16 色）**——统一才有质感，颜色越杂越廉价。

## 第一步：锁定一种美术风格（六选一，全程不改）

### 1. 像素风 Pixel Art
- 关键词：复古、颗粒感、整数缩放、无抗锯齿、描边、抖动阴影（dithering）
- 规则：所有图元用整数坐标与整数缩放；禁用模糊/渐变；轮廓线统一 1px 深色描边
- 适用：怀旧街机、Roguelike、平台跳跃、Minecraft/星露谷类模组

### 2. 扁平风 Flat / Material
- 关键词：明亮、圆角、纯色块、单层柔和投影、无描边
- 规则：大色块 + 圆角（8–16px）+ 一层低透明度阴影；避免渐变和立体高光
- 适用：休闲手游、益智、卡牌、UI 密集型游戏

### 3. 霓虹风 Neon / Cyberpunk
- 关键词：深色底、高饱和霓虹、发光（glow）、几何线条、扫描线
- 规则：背景必须深（接近纯黑/深蓝）；前景用霓虹色 + box-shadow 发光；大量网格线与几何图形
- 适用：赛博朋克、音游、科幻射击

### 4. 卡通风 Cartoon
- 关键词：高饱和、粗描边、大圆眼、夸张比例、明快
- 规则：3–4px 粗描边；角色比例夸张（头大身小）；用纯色高光替代真实渐变
- 适用：儿童向、派对游戏、养成、休闲消除

### 5. 低多边形 Low-poly
- 关键词：三角面、柔和光照、柔和渐变、扁平几何
- 规则：模型用少量三角面；光照柔和无硬阴影；颜色低饱和但层次丰富
- 适用：3D 休闲、模拟经营、风景探索

### 6. 极简风 Minimal
- 关键词：黑白灰、单一强调色、大量留白、几何构成
- 规则：主界面只用黑白灰；全游戏只用一个强调色（如一种红/蓝/绿）用于关键交互
- 适用：解谜、策略、极简禅意游戏

## 第二步：固定一套调色板（每套游戏都要有，且写进代码常量）

按这个顺序定色，并把每个色值写进代码顶部常量，全游戏引用、禁止硬编码散落：

1. **背景色**（最暗或最亮，占画面 60%）
2. **主色**（品牌/主角，占 30%）
3. **强调色**（交互/得分/按钮，占 10%）
4. **危险色 / 警告色**（敌人、扣血、错误）
5. **文字色**（前景、次级文字各一个）

现成色板示例（选一个直接套用，可微调）：

- 像素风：背景 `#1a1c2c`，主色 `#5dcbaa`，强调 `#ef9f27`，危险 `#e24b4a`，文字 `#f1efe8`
- 扁平风：背景 `#f5f7fa`，主色 `#378add`，强调 `#22c55e`，危险 `#ef4444`，文字 `#1f2937`
- 霓虹风：背景 `#0a0a14`，主色 `#00e5ff`，强调 `#ff2d95`，危险 `#ff1744`，文字 `#e0f7fa`
- 卡通风：背景 `#ffe9b0`，主色 `#ff8a3d`，强调 `#3ddc84`，危险 `#ff4757`，文字 `#3d2b1f`
- 低多边形：背景 `#2b3a4a`，主色 `#7fbfa0`，强调 `#f0c987`，危险 `#c96a5b`，文字 `#e8eef2`
- 极简风：背景 `#ffffff`，主色 `#111111`，强调 `#e11d48`，危险 `#dc2626`，文字 `#111111`

## 第三步：按平台适配（必须判断目标平台再写）

### 手机游戏
- 触控按钮尺寸 ≥ 44px（拇指热区），间距 ≥ 8px；适配刘海/异形屏安全区
- 性能优先：减少粒子数量、少用大阴影/模糊、动画用 transform 而非重绘
- 横竖屏固定一种，不要动态乱切

### 网页游戏
- 响应式布局，桌面/移动都能玩；Canvas 用设备像素比做高清适配
- 可放心用高特效（粒子、shader、字体）；字体优先 web 安全字体或引入本地字体文件

### 游戏模组（Mod）
- **第一铁律：严格贴合目标游戏原有的美术风格**——先看原游戏的贴图、调色板、素材尺寸，再动手
- 像素游戏（Minecraft、星露谷、泰拉瑞亚）→ 复用原版 16/32px 像素规格与调色板
- 写实/低模游戏（天际线、模拟人生）→ 用低模 + 柔和光照，不要卡通化
- 体积游戏（Minecraft）→ 体素 16×16×16，贴图 16×16 像素，遵守原版 UV 与法线规范
- 模组的图标/UI 也要对齐原版样式，否则一眼出戏

## 第四步：技术实现（选对工具，画面立刻上一个档次）

- **网页 / 手机 H5 游戏**：优先 Kaplay（原 Kaboom.js，内置粒子/动画/渲染）、Phaser、PixiJS；不要用裸 Canvas 手搓
- **特效**：爆炸/火焰/烟尘用粒子系统；闪烁/脉冲用缓动动画；氛围用 shader
- **素材**：优先用现成免费素材库——Kenney.nl、OpenGameArt、itch.io 免费包；下载 spritesheet 直接用，**不要自己用代码画**
- **程序化生成**：地形/纹理用 Perlin/Simplex 噪声；星空/粒子用随机 + 缓动

## 第五步：交付前自检（全过才算完成）

- [ ] 全游戏只有一种风格、一个调色板，色值集中在代码常量里
- [ ] 主色 / 强调色 / 危险色有明确区分，不混用
- [ ] 没有 CSS 纯色块硬画（用了引擎 / 素材 / 程序化之一）
- [ ] UI 有层级：背景 < 内容 < 前景 < 弹窗，弹窗有遮罩
- [ ] 动画都有缓动（ease-in / ease-out），没有生硬的线性运动
- [ ] 字体、圆角、间距、描边宽度全游戏一致
