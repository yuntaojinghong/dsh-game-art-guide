# 游戏美术全规范

目标：让 AI 生成的游戏达到「风格统一、配色讲究、动效有质感」的水准，而不是一堆 CSS 纯色块。全程只做一件事——**先定风格和配色，再写代码**。

## 核心原则（违反任何一条画面都会崩）

1. **不用 CSS 纯色块硬画**——画面表现靠引擎、现成素材或程序化生成，三者至少用一种。
2. **先定风格 + 配色，再动手**——风格是骨架，中途换风格等于推倒重来。
3. **一游戏一风格一调色板（≤16 色）**——统一才有质感，颜色越杂越廉价。

## 一、美术风格库（10 选 1，选定后全程锁定）

### 1. 像素风 Pixel Art
- 定位：复古颗粒感、整数缩放、无抗锯齿
- 配色：低饱和高对比，16 色板；背景 `#1a1c2c`，主色 `#5dcbaa`，强调 `#ef9f27`，危险 `#e24b4a`
- 规则：图元整数坐标与整数缩放；禁用模糊/渐变；1px 深色描边；阴影用抖动（dithering）
- 适用：街机、Roguelike、平台跳跃、Minecraft/星露谷类模组

### 2. 扁平风 Flat / Material
- 定位：明亮、圆角、纯色块、单层柔和投影
- 配色：背景 `#f5f7fa`，主色 `#378add`，强调 `#22c55e`，危险 `#ef4444`，文字 `#1f2937`
- 规则：大色块 + 圆角（8–16px）+ 一层低透明度阴影；禁渐变和立体高光
- 适用：休闲手游、益智、卡牌、UI 密集型游戏

### 3. 霓虹风 Neon
- 定位：深色底、高饱和霓虹、发光、几何线
- 配色：背景 `#0a0a14`，主色 `#00e5ff`，强调 `#ff2d95`，危险 `#ff1744`，文字 `#e0f7fa`
- 规则：背景必须深（近纯黑/深蓝）；前景霓虹色 + box-shadow 发光；大量网格线与几何图形
- 适用：音游、科幻射击、跑酷

### 4. 卡通风 Cartoon
- 定位：高饱和、粗描边、夸张比例、明快
- 配色：背景 `#ffe9b0`，主色 `#ff8a3d`，强调 `#3ddc84`，危险 `#ff4757`，文字 `#3d2b1f`
- 规则：3–4px 粗描边；角色头大身小；纯色高光替代真实渐变
- 适用：儿童向、派对、养成、休闲消除

### 5. 低多边形 Low-poly
- 定位：三角面、柔和光照、扁平几何
- 配色：背景 `#2b3a4a`，主色 `#7fbfa0`，强调 `#f0c987`，危险 `#c96a5b`，文字 `#e8eef2`
- 规则：模型少量三角面；光照柔和无硬阴影；颜色低饱和但层次丰富
- 适用：3D 休闲、模拟经营、风景探索

### 6. 极简风 Minimal
- 定位：黑白灰、单一强调色、大量留白、几何构成
- 配色：背景 `#ffffff`，主色 `#111111`，强调 `#e11d48`，危险 `#dc2626`，文字 `#111111`
- 规则：主界面黑白灰；全游戏只用 1 个强调色标记关键交互
- 适用：解谜、策略、极简禅意游戏

### 7. 国风水墨 Ink / Guofeng
- 定位：水墨晕染、留白、宣纸质感、朱砂点缀
- 配色：纸底 `#f5efe0`，墨色 `#2b2b2b`，朱砂 `#c0392b`，青绿 `#3a7d5c`，描金 `#b8860b`
- 规则：大留白；线条有浓淡枯笔变化（用透明度渐变模拟）；印章式红色点缀；圆角柔和、避免锐利直角
- 适用：武侠、仙侠、棋牌、国风解谜

### 8. 赛博朋克 Cyberpunk
- 定位：霓虹 + 锈蚀 + 全息投影 + 雨夜都市
- 配色：背景 `#0d0d1a`，主色 `#ff2d95`，强调 `#00e5ff`，危险 `#ff3b3b`，辅助 `#ffb300`
- 规则：比霓虹风更「脏」——叠加噪点、扫描线、故障（glitch）色差；暗部带冷紫、亮部带暖黄；全息 UI 用细线框 + 半透明
- 适用：赛博主题动作、黑客、赛博 2077 类

### 9. 水彩手绘 Watercolor
- 定位：柔和晕染、纸纹、手绘笔触
- 配色：纸底 `#fdf6ec`，主色 `#6ea8c9`，强调 `#e8a87c`，危险 `#c96a5b`，文字 `#4a4a4a`
- 规则：颜色边缘有柔和扩散（径向渐变或 blur）；叠纸纹理；避免生硬描边；笔触有粗细变化
- 适用：绘本、治愈、叙事冒险

### 10. 蒸汽朋克 Steampunk
- 定位：黄铜、齿轮、皮革、铆钉、蒸汽暖光
- 配色：底 `#2a2118`，黄铜 `#b8860b`，皮革 `#6b4226`，强调 `#d98e32`，文字 `#e8dcc8`
- 规则：金属用黄铜/古铜渐变；大量圆形齿轮、铆钉、管道元素；暖色灯光；材质粗糙有颗粒
- 适用：蒸汽朋克解谜、策略、建造

## 二、配色系统（每套游戏都要固定，写进代码常量）

按「五色定位法」定色，色值写进代码顶部常量、全游戏引用，禁止散落硬编码：

1. **背景色**（画面 60%，最暗或最亮）
2. **主色**（品牌/主角，30%）
3. **强调色**（交互/得分/按钮，10%）
4. **危险/警告色**（敌人、扣血、错误）
5. **文字色**（前景 + 次级文字各一个）

规则：主色与强调色要有足够对比；危险色不与主色混用；同一色系明暗变化用 HSL 调整（改 L 不改 H），保证和谐。

## 三、UI 与动画规范

### HUD / 界面层级（从下到上）
1. 背景层（场景/底色）
2. 内容层（角色、物体、棋盘）
3. HUD 层（分数、血条、按钮）
4. 弹窗层（半透明遮罩 `rgba(0,0,0,0.4~0.6)` + 居中面板）

### 菜单 / 按钮 / 弹窗
- 按钮主操作用主色，次级用描边/幽灵按钮；热区 ≥ 44px（手机）
- 弹窗圆角 12–16px，进入用缩放+淡入，退出反向
- 字体按钮内文字垂直居中，禁用文字贴边

### 缓动曲线（不要线性）
- 常规 UI：`cubic-bezier(0.25, 0.1, 0.25, 1)`（ease）
- 弹窗进入：`cubic-bezier(0.34, 1.56, 0.64, 1)`（带回弹）
- 物体移动：`cubic-bezier(0.4, 0, 0.2, 1)`
- 强调动作（得分/连击）：`cubic-bezier(0.68, -0.55, 0.265, 1.55)`（回弹）

### 动效时长
- 按钮反馈 100–150ms；面板/弹窗 200–300ms；过场 400–600ms；粒子 1–2s
- 所有动画都要有 ease，禁止生硬线性

## 四、游戏类型针对性要点

- **平台跳跃**：角色轮廓要一眼可辨（粗描边或高对比剪影）；跳跃轨迹要有挤压拉伸（squash & stretch）；背景用视差分层
- **RPG**：装备图标统一尺寸与风格；对话立绘表情差分；战斗技能特效有粒子 + 屏幕震动
- **塔防**：塔/敌人用色区分阵营（友=冷色，敌=暖色或反之）；攻击弹道清晰；血条统一在头顶
- **三消/消除**：糖果/宝石用高饱和纯色 + 高光；消除动画要有粒子迸发 + 连击放大反馈
- **射击**：子弹/弹道高亮发光；命中火花粒子；敌人中弹闪白（hit flash）
- **卡牌**：卡牌统一比例（如 2.5:3.5）；稀有度用边框颜色区分（白/绿/蓝/紫/金）；出牌动画有弧线
- **模拟经营**：建筑图标俯视 45° 或纯正面；资源图标可读性优先；界面信息密度低、留白多

## 五、中文字体排版

- 字体：网页优先 `"PingFang SC"`、`"Microsoft YaHei"`、`"Noto Sans SC"`；像素游戏用思源黑体或像素中文字体
- 字号层级：标题 24–32px、正文 14–16px、辅助 12px；手机游戏正文字号 ≥ 14px
- 字重：标题 500–700，正文 400；避免大量粗体
- 数字/英文：用等宽或专用游戏数字字体；数字与中文混排加空格
- 行高 1.5–1.6；按钮内文字单行不换行

## 六、技术实现与素材

- **引擎**：网页/手机 H5 用 Kaplay（原 Kaboom.js）、Phaser、PixiJS；不要裸 Canvas 手搓
- **特效**：爆炸/火焰/烟尘用粒子系统；脉冲/闪烁用缓动；氛围用 shader
- **素材库**（优先用现成，别自己画）：Kenney.nl（全风格 spritesheet）、OpenGameArt、itch.io 免费包
- **程序化**：地形/纹理用 Perlin/Simplex 噪声；星空/粒子用随机 + 缓动
- **模组**：严格复用目标游戏原版调色板与素材尺寸（Minecraft 16×16、星露谷像素风等）

## 七、交付前自检（全过才算完成）

- [ ] 全游戏只有一种风格、一个调色板，色值集中在常量里
- [ ] 主色 / 强调色 / 危险色区分明确，不混用
- [ ] 没有 CSS 纯色块硬画（用了引擎 / 素材 / 程序化之一）
- [ ] UI 层级正确（背景 < 内容 < HUD < 弹窗 + 遮罩）
- [ ] 动画全部有缓动，时长符合规范（按钮 100–150ms 等）
- [ ] 中文字体、字号、行高全游戏一致
- [ ] 手机版按钮热区 ≥ 44px，适配安全区
